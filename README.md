# dashboard-operativo-analitico

## 📌 Descripción

Dashboard operativo analítico (frontend) para monitorear KPIs de negocio, analizar tendencias y exportar reportes. Forma parte de un portafolio personal que demuestra buenas prácticas de programación, organización y documentación en GitHub.

## 🧱 Stack

- **React + TypeScript + Vite**
- **yarn** como gestor de paquetes
- **shadcn/ui** + Tailwind CSS v4
- **animejs** para animaciones
- **Recharts** para gráficos
- **vitest** para tests
- Diseño según la skill **hallmark** (tema **Hum**)
